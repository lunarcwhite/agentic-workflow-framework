## Commands Tested

```bash
# 1. Audit HTML document
python tools/uaf.py seo audit docs/index.html --threshold 85

# 2. Generate Schema.org JSON-LD
python tools/uaf.py seo generate --type SoftwareApplication --name "UAAF" --description "AI Agent Governance" --url "https://example.com"

# 3. Install and govern landing-page-seo plugin
python tools/uaf.py plugin install landing-page-seo

# 4. Export plugin to target agent harnesses
python tools/uaf.py plugin export landing-page-seo --target all

# 5. Compose team with landing page and SEO specialists
python tools/uaf.py team compose "Design high converting SaaS landing page and optimize technical SEO" --pattern fan_out_fan_in

# 6. Verify deliverables and conformance
python tools/uaf.py check
```
