## Conformance warning interpretation

Fresh generated projects can report two non-fatal inherited scaffold warnings:

- `CONF-REF-001 source_of_truth.memory points to missing path .ai/memory/entries`
- `CONF-DOC-001 placeholder content remains in .ai/core/CONTEXT.md`

These warnings predate the v3 runtime and do not produce conformance errors. The v3 runtime itself reports no conformance errors.

## Known validation-environment limitation

The historical v2.9 runner can emit `TERM environment variable not set` after completion in the execution environment. The test suite itself completed with `v2.9 PASS` and `ALL 3/3 PASSED`; environment noise was not treated as a passing signal.

## Release decision evidence

No timeout is counted as a pass. The release gate is supported by completed fresh-process/in-process validation, explicit negative-path tests, and an archive smoke test performed after packaging.
