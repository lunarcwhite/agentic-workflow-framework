# UAAF v2.5 Implementation Notes

## Implemented

- `tools/uaf_federation_transport.py`
- unified CLI command `federation-transport`
- adaptive initializer support for `--extension v2.5`
- `CONF-V25-*` conformance checks
- compact doctor integration
- v2.4 contract dependency
- signed channel open/accept/confirm handshake
- session binding
- project/identity audience separation
- signed sequenced messages
- replay/out-of-order rejection
- signed resume and resume anti-replay
- transport audit hash-chain compatible metadata

## Reference transport scope

The implementation intentionally uses files as a deterministic loopback/reference carrier. It is not a socket server and it does not claim to provide confidentiality.

Network/TLS/QUIC/WebSocket implementations can transport the same authenticated envelopes later without changing authority or policy semantics.

## CLI security requirements

Private keys are supplied externally and are never persisted under `.ai/`. Public peer pins are stored under the existing federation peer trust namespace.
