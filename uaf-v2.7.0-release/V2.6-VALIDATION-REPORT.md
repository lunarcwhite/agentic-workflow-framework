## Test Harness Limitation

The combined multi-version test runner can exceed the execution harness time limit because UAAF tests create many subprocesses and cryptographic fixtures. A timeout in the combined runner is therefore not treated as a test result. Acceptance is based on completed fresh-process scenario runs and archive smoke tests.
