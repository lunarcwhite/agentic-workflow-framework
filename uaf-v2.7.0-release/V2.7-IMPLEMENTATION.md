# UAAF v2.7 Implementation Notes

## Implemented
- `tools/uaf_key_lifecycle.py`
- `uaf key-lifecycle ...` unified CLI command
- v2.7 adaptive initializer support
- v2.7 conformance checks
- compact v2.7 doctor path
- v2.6 confidential transport lifecycle guards

## Lifecycle storage

```text
.ai/federation/secure/
├── CHANNELS/
├── INBOX/
├── OUTBOX/
├── keys/
├── LIFECYCLE.yaml
├── KEY-REVOCATIONS.yaml
├── KEY-STORAGE.yaml
└── AUDIT.jsonl
```

## Reference provider
Provider reference = `filesystem`.

Key retirement uses best-effort file deletion and records a non-secret retirement receipt. The implementation does not claim guaranteed secure/forensic erasure of blocks or filesystem snapshots.

## Recovery semantics
Recovery does not reconstruct private ephemeral key state. A missing private key on an active channel changes state to `RECOVERY_REQUIRED`; a new authenticated channel handshake is required.

Terminal channels remain terminal during recovery.

## Transport integration
v2.6 send/receive/rekey now consult lifecycle state and reject non-open channels with a canonical reason:

```text
CHANNEL_LIFECYCLE_CLOSED
CHANNEL_LIFECYCLE_EXPIRED
CHANNEL_LIFECYCLE_REVOKED
CHANNEL_LIFECYCLE_RECOVERY_REQUIRED
```

## Compatibility
Requesting `v2.7` installs the cumulative v2.6 secure transport plus v2.7 lifecycle artifacts. Downgrading to `v2.6` removes only known v2.7 artifacts and preserves the v2.6 secure namespace.
