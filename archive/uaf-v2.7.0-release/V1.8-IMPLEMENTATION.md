## Safety properties

- No implicit authentication claim.
- Capability and authority are distinct metadata.
- Delegation is bounded by parent authority.
- Capability/domain/risk escalation is rejected.
- Expiry is explicit.
- Revocation invalidates the delegation.
- Trust decisions are categorical, not a numeric score.
- Audit output is metadata-only.

## Non-goals

The reference implementation does not replace enterprise IAM, OS permissions, Git permissions, signed agent identities, or remote policy enforcement.
