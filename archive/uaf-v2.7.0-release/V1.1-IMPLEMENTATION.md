# UAAF v1.1 Implementation Increment

Implemented extensions:

1. Capability Override Contract — `tools/uaf_capabilities.py`
2. Context Impact Graph — `tools/uaf_context_impact.py`
3. Unified CLI — `tools/uaf.py`
4. Extension conformance — `tools/uaf_check.py`

Invocation:

```bash
python tools/uaf.py init ./project --profile full --auto-detect --extension v1.1
python tools/uaf.py capabilities ./project show
python tools/uaf.py capabilities ./project set frontend=force_false --reason "Not a separately maintained frontend."
python tools/uaf.py impact ./project --paths src/components/Button.tsx docs/design/DESIGN.md --write
python tools/uaf.py check ./project --level full
python tools/uaf.py doctor ./project --level full
```

The current release deliberately defers memory compaction, stronger RCE, Git traceability, real claim leasing, security diagnostics, and runtime verification adapters.
