# UAAF v2.1 Implementation Notes

## Extensions

- `tools/uaf_federation_ops.py` implements operational mode, sync, conflicts, revocations, checkpoints/recovery, and observability.
- `tools/uaf_check.py` adds `CONF-V21-*`.
- `tools/uaf_doctor.py` adds a bounded federation-operations diagnostic.
- `tools/uaf.py` exposes `federation-ops`.
- `tools/uaf_init.py` supports `--extension v2.1` and isolates v2.1 artifacts from v2.0 installs.

## Safety invariants

1. Operational mode never changes authority.
2. Sync import is idempotent and remains protected by v2.0 replay checks.
3. Revocations must be signed by a trust root and propagate only after peer-root verification.
4. Conflicts cannot skip lifecycle states.
5. Recovery requires RECOVERING mode and creates a recovery backup.
6. Recovery never replaces the local replay store and never silently discards unresolved local conflicts.
7. Federation observability stores metadata only.

## CLI

`python tools/uaf.py federation-ops <command> ...`

Commands: `mode`, `status`, `sync-export`, `sync-import`, `conflicts`, `conflict-propose`, `conflict-transition`, `revoke`, `revoke-import`, `checkpoint-create`, `checkpoint-verify`, `checkpoint-recover`, `observe`.
