# TASK-0001 — Make task completion idempotent

status: completed
scope: FEATURE
domain: BACKEND
risk: LOW

## Intent
Allow callers to safely request task completion more than once without changing the result or introducing an error.

## Requirements

### REQ-001
`complete_task` marks an incomplete task as completed.

### REQ-002
Calling `complete_task` on an already completed task leaves it completed and does not create a new state transition.

## Constraints
- Keep the change dependency-free.
- Reuse the existing `Task` model.

## Non-goals
- Persistence redesign.
- API redesign.

## Acceptance criteria
- GIVEN an incomplete task, WHEN `complete_task` is called, THEN `completed` becomes true.
- GIVEN a completed task, WHEN `complete_task` is called, THEN the task remains completed.

## Verification
- `python -m pytest test_src.py`

## Change budget
Only the task completion implementation and directly related tests.
