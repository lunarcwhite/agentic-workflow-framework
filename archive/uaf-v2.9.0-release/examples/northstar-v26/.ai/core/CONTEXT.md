# Northstar Reference Context

Northstar is the reference project used to demonstrate a Full-profile UAAF installation with v2.6 confidential federation transport.

Purpose: demonstrate project knowledge, verification, and federation transport scaffolding without embedding private key material or assuming a production network.

Project type: reference/fullstack-style example.

Security boundary: v2.6 confidential transport is enabled as a capability, but no live peer contract or private signing material is shipped in this example. A fresh install therefore reports confidential transport as `NOT_CONFIGURED` until the operator completes trust and v2.4 negotiation setup.

Canonical implementation state remains the repository itself.
