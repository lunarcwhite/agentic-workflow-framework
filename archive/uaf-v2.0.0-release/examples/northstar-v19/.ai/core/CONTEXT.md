# Northstar Project Context

Purpose: small full-stack reference project used to exercise UAAF lifecycle, verification, memory, governance, and traceability.

Users: development agents and maintainers.

Stack: Python reference application with repository-level UAAF documentation and tooling.

Architecture summary: small application module plus test module; UAAF knowledge is stored under `.ai` and canonical project docs under `docs`.

Constraints: UAAF governance remains explicit-approval; no secrets are stored in UAAF artifacts.

Special cases: Northstar is a reference fixture, not a production application.
