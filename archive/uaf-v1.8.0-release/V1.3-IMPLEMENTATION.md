# UAAF v1.3 Implementation Notes

## Git Traceability

`uaf_git_trace.py` records an explicit Git baseline and traces committed changes plus current worktree changes. It also reports whether a referenced task artifact exists and which commits mention the task ID. No Git history is modified.

## Real Claim Leasing

`uaf_claims.py` stores claims in `.ai/agents/CLAIMS.yaml` and protects mutation with `.ai/agents/.claims.lock`. Active conflicts block acquisition. Expired claims are detected but remain blocking until `reclaim` explicitly marks them `RECLAIMABLE`. Release requires the owning agent unless an explicit force path is used.

## Runtime Verification

`uaf_runtime.py` only executes when the project policy is enabled and the exact argv sequence is present in `allow`. Commands use `shell=False`, have a timeout, and write a bounded runtime evidence receipt with status `VERIFIED`, `FAILED`, or `BLOCKED`.

## Unified CLI

New commands: `git`, `claims`, `runtime`. v1.3 initialization is cumulative and does not alter v1.0-v1.2 projects unless explicitly selected.
