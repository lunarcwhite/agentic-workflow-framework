## Safety observations

- v2.0 remains Full-profile only.
- Federation files are generated only when v2.0 is explicitly requested.
- Legacy v1.x initialization does not emit `.ai/federation`.
- Private keys are not generated inside project repositories.
- Federation identity and policy signatures remain detached from private key material.
