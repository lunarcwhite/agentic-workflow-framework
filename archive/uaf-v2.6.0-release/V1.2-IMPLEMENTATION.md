# UAAF v1.2 Implementation Notes

## Memory Compaction

`tools/uaf_memory_compact.py` implements a conservative, deterministic compaction flow. It scans ACTIVE and VALIDATED memory entries, clusters highly similar entries using lexical token similarity, selects a stable canonical entry, and archives duplicates only when `--apply` is explicit.

The command is read-only by default:

```bash
python tools/uaf.py memory <project> compact
python tools/uaf.py memory <project> compact --check
python tools/uaf.py memory <project> compact --apply
```

## Strong RCE

`tools/uaf_rce_strong.py` adds fingerprint-based reality validation. `snapshot` writes `.ai/health/REALITY-INDEX.yaml`; `scan` compares current files with that baseline and checks canonical owners plus knowledge references.

```bash
python tools/uaf.py rce <project> snapshot
python tools/uaf.py rce <project> scan
```

The scan does not rewrite canonical knowledge.
