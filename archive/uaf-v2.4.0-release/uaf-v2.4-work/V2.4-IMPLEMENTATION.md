## Safety model

Protocol negotiation is separate from authority. v2.3 policy enforcement remains authoritative for allowed actions. v2.4 can only choose a compatible communication contract.

Fallback requires explicit declaration by both peers. Required features that become unavailable do not become silently optional.

## Distribution separation

v2.4 tooling stays in the distribution layer. An initialized project receives only `.ai/federation/protocol/*` knowledge/state artifacts and does not receive the UAAF development repository or Python source tree.
