# UAAF v2.3 Implementation Notes

Implemented in the distribution CLI:

- `federation-negotiation offer`
- `federation-negotiation negotiate`
- `federation-negotiation check`
- `federation-enforce enforce`
- `federation-enforce check`

The initializer emits the v2.3 negotiation namespace only when `--extension v2.3` is explicitly selected. Downgrading to v2.2 removes the v2.3 negotiation artifacts without deleting unrelated project files.

The enforcement layer is deny-first and recognizes `domain_scope` so a disjoint domain intersection cannot be misinterpreted as unrestricted access.
