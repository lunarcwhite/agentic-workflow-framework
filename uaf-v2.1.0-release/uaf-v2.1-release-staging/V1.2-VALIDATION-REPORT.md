# UAAF v1.2.0 Validation Report

Status: VALIDATED
Date: 2026-09-26

## Scope

This release adds two additive extensions on top of UAAF v1.1:

- Conservative Memory Compaction
- Strong Reality & Consistency Engine (RCE) with SHA-256 snapshots

UAAF v1.0 core semantics remain unchanged.

## Functional Verification

### Memory Compaction

- duplicate detection is deterministic;
- dry-run is the default;
- explicit apply archives duplicates instead of deleting them;
- canonical selection is stable under equal metadata;
- `MEMORY.md` is rebuilt after apply;
- compaction records preserve source IDs through the archive and report.

### Strong RCE

- snapshot records SHA-256 fingerprints for relevant referenced files;
- scan detects fingerprint drift;
- missing canonical owners are errors;
- missing evidence sources are errors;
- memory references to TASK/DEC/EVD/MEM IDs are checked;
- impact-graph paths are checked;
- scan remains read-only.

### Compatibility

- v1.1 projects do not receive v1.2 artifacts unless initialized with `--extension v1.2`;
- v1.0/v1.1 conformance behavior remains available;
- unified CLI exposes v1.2 features without changing core semantics.

## Smoke Test

Validated flow:

`uaf init --extension v1.2` → `uaf rce snapshot` → `uaf rce scan` → `uaf memory compact` → `uaf doctor`.

The fresh scaffold produced only expected advisory warnings: no impact graph had been generated yet and kernel placeholders remained.
