## Harness note

The repository's cumulative pytest runner can exceed the execution harness time limit because many tests spawn cryptographic subprocesses. v2.5 acceptance therefore uses fresh-process per-test execution plus CLI smoke tests. Timeouts in the combined harness are not counted as test failures unless an individual test returns a failure exit code.
