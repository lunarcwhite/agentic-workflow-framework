# UAAF v2.9 — Secure Key Operations & Provider-backed Signing

Provider custody is now an active cryptographic boundary. `key_id`/key references are resolved through the configured provider, signatures are returned without private-key material, and federation confidential-channel handshake operations can sign through `--key-ref`.

Reference filesystem provider: private signing material must live under the externally configured `UAAF_KEY_DIR`, outside the repository. KMS/HSM/OS-keychain remain adapter contracts unless a real provider is configured.
