# UAAF v1.5 Implementation Notes

UAAF v1.5 adds Context Economics & Observability as an additive Full-profile extension.

## Implemented

- `tools/uaf_observe.py` — metadata-first observability recorder/report/checker.
- `tools/uaf.py observe` — unified CLI dispatch.
- initializer support for `--extension v1.5`.
- conformance rules `CONF-V15-*`.
- doctor integration.
- context receipt token-volume estimation.
- memory stale-rate and compaction metrics.
- explicit memory reuse, gate, and replan events.
- configurable observability budgets.
- privacy guard preventing prompt/content/secret fields from being persisted by the recorder.

## Design constraints

The extension does not expose a universal performance score. Missing telemetry is `NOT_ENOUGH_DATA`. Token counts are size-based estimates, not provider billing/tokenization truth.

Threshold violations return `WARN` and do not mutate project state.

## Context Receipt integration

The canonical `templates/context-receipt.yaml` now includes optional `estimated_tokens` and `usage.used`/`usage.unused` fields so agents can emit observability data without storing prompt/source contents.
