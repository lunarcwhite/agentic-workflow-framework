Core Axioms

Built for Reliability, Bounded by Design

Autonomous agents fail when given unconstrained autonomy. UAAF turns chaotic generative guessing into predictable, contract-driven engineering.

Anti-Slop Invariants

Strictly prohibits silent scope creep, fake completion claims, and lazy placeholders (// TODO). Forces agents to understand existing code before inventing new abstractions.

Verifiable Evidence Receipts

No task can be marked complete based on conversational assertions alone. Agents must anchor reproducible command outputs, exit codes, and test logs into tamper-evident receipts.

Lossless State Compactor

Prevents long-horizon context degradation. Compresses token-heavy trajectories into structured durable states, enabling seamless handoffs across unlimited agent turns.

Confidential Federation

Enables decentralized multi-agent collaboration with X25519 ephemeral handshakes, ChaCha20-Poly1305 authenticated encryption, and abstracted key custody providers.

Deterministic Flow

The Deterministic Agent Lifecycle

How UAAF guides an agent from instruction to verifiable delivery without human micro-management.

STEP 01

Task Contract

Explicit goals, permitted file scopes, and acceptance criteria defined in task-contract.yaml.

STEP 02

Kernel Execution

Agent works bounded by Golden Axioms: Understand > Inspect > Search > Reuse > Minimal Edits.

STEP 03

Quality Gates

Conformance checks run automatically via uaf check to confirm zero regressions.

STEP 04

Evidence Receipts

Execution proof and token economics are logged deterministically in evidence-receipt.yaml.

STEP 05

Durable Handoff

State compactor persists durable memory for the next agent session without context bloat.

Developer Setup

Get Started in 60 Seconds

Install the CLI or use UAAF purely as a prompt-and-scaffold protocol without any Python runtime.

# 1. Clone repository & install CLI globally in editable mode
git clone https://github.com/lunarcwhite/universal-agent-framework.git
cd universal-agent-framework
pip install -e .

# 2. Initialize UAAF in your target project
uaf init ./my-project --profile standard --auto-detect

# 3. Check health and run conformance verification
uaf doctor ./my-project
uaf check ./my-project
# Works for Node.js, Go, Rust, Java, PHP, or any non-Python codebase!
# 1. Copy the knowledge scaffold directly into your project root:
cp -r scaffold/.ai/ ./my-project/.ai/
cp AGENTS.md ./my-project/AGENTS.md

# 2. Your AI coding editor (Cursor, Antigravity, Claude Code, Windsurf)
# will read AGENTS.md and .ai/ natively — zero dependencies required!
# Initialize full Federated Agent Runtime (v3.0.1)
uaf init ./node-alpha --profile full --extension v3.0.1

# Check provider key custody & open encrypted channel
uaf key-storage check ./node-alpha
uaf federation open ./node-alpha --peer node-beta.domain --channel-id SC-9042
