Anatomy of Failure

The 5 Deadly Sins of AI Coding Slop

How unregulated AI models fail in real codebases — and the deterministic UAAF protocol engineering that cures each one.

Sin 01

The Phantom Pass

AI Slop Behavior

The model politely announces: "I ran pytest and all 42 tests passed with zero errors!" In reality, the tool was never invoked, exit codes were never inspected, or test assertions were silently commented out.

UAAF VEE-1.0 Receipt

Conversational claims are denied. Task transitions require an immutable evidence-receipt.yaml containing exact command argv, exit code 0, test stdout/stderr, and cryptographic output hashes.

Sin 02

The Lazy Stub (// TODO Syndrome)

AI Slop Behavior

When generating complex logic or edge-cases, the agent writes // TODO: implement error handling here or returns mock empty arrays return [] and claims the user story is fully delivered.

UAAF ASE-1.0 Hard Gate

Rejects known incompleteness presented as complete. Automated AST scanning inspects modified files for placeholder stubs, unfinished blocks, and mock bypasses before quality gates unlock.

Sin 03

Silent Scope Creep

AI Slop Behavior

Asked to adjust a CSS padding, the agent refactors the entire design system, alters ESLint rules, downgrades packages, and mutates 27 files you never authorized.

UAAF Task Contract & Leases

Execution is bounded by task-contract.yaml specifying explicit permitted_files. The runtime leases file claims; any diff outside the leased perimeter halts execution instantly.

Sin 04

Long-Horizon Context Amnesia

AI Slop Behavior

After 12 prompts, chat history exceeds context limits. The model forgets decisions made 10 minutes ago, re-invents deleted bugs, and enters an infinite hallucination loop.

UAAF Lossless State Compactor

Extracts ephemeral tokens into structured durable state (.ai/memory/STATE.md). Generates clean handoffs so subsequent agent sessions resume with exact knowledge and zero bloat.

Sin 05

Framework Fantasy & Over-Abstraction

AI Slop Behavior

The agent invents 5 layers of redundant abstract factory classes, adds speculative utilities, or hallucinates non-existent npm/pypi packages that trigger security incidents.

UAAF Purpose Gate & RCE Engine

Axiom 4 mandates: Reuse → extend → modify → create. Every new dependency or abstraction must provide verified purpose receipts before code can merge.

The Three Anti-Slop Enforcement Gates

Formal architectural filters defined in .ai/anti-slop/GATES.md that cannot be bypassed by chat instructions.

NON-NEGOTIABLE

HARD GATE

Immediate execution rejection upon violation. No model reasoning or prompt engineering can override this gate.

  • Fabrication & Hallucinated APIs
  • Fake Verification (NOT_RUN ≠ PASS)
  • Silent Scope Expansion (Unleased Files)
  • Intent Replacement or Goal Drift
  • Known Incompleteness Claimed as Done
  • Secret & Credential Leakage
JUSTIFICATION

PURPOSE GATE

Prohibits speculative extensibility and framework fantasy. Divergence requires concrete repository justification.

  • New Architectural Abstractions
  • External Dependency Introductions
  • Major Unsolicited File Refactoring
  • Decorative Motion & CSS Fluff
  • Pattern Divergence from Codebase Style
  • Speculative Extensibility Layers

QUALITY LOCK

Guarantees zero regressions and strict consistency across long-horizon agent handoffs.

Kernel Invariants

The 10 Golden Rules of Agentic Engineering

Embedded inside AGENTS.md and verified by the UAAF Agent Kernel before any consequential action.

01

Understand before changing.

Read manifests, architecture records, and established state before touching production lines.

02

Inspect before inventing.

Audit existing modules and utilities before writing new helper functions or synthetic wrappers.

03

Search before creating.

Grep and semantically index the codebase to reuse existing conventions and design tokens.

04

Reuse → extend → modify → create.

The strict priority cascade. Creating new code is the last resort when extension is impossible.

05

Preserve user intent.

Never replace the user's underlying goal with an easier sub-goal or simplified approximation.

06

Never silently expand scope.

Edits are restricted strictly to files declared in the leased task contract perimeter.

07

Treat memory as hypothesis.

Past claims and conversation memories are unverified until proven against active disk state.

08

Evidence before completion.

No task can be declared done without a verifiable, reproducible evidence receipt.

09

Keep changes minimal & complete.

Surgical precision. Zero leftover scaffolding, zero partial stubs, and zero formatting churn.

10

Persist durable handoffs.

Compress session trajectory into durable state so the next agent turn resumes seamlessly.

Developer Setup

Start Bounding Your Agents in 60 Seconds

Use the Python CLI or drop UAAF directly into any repository as a pure prompt-and-knowledge scaffold.

# 1. Clone repository & install CLI globally in editable mode
git clone https://github.com/lunarcwhite/universal-agent-framework.git
cd universal-agent-framework
pip install -e .

# 2. Initialize UAAF with standard Anti-Slop profile
uaf init ./my-project --profile standard --auto-detect

# 3. Check health and run automated anti-slop verification
uaf doctor ./my-project
uaf check ./my-project
# Works for TypeScript, Go, Rust, Java, C#, PHP, or any codebase!
# 1. Copy the knowledge scaffold and agent kernel into your project root:
cp -r scaffold/.ai/ ./my-project/.ai/
cp AGENTS.md ./my-project/AGENTS.md

# 2. Open in Cursor, Claude Code, Antigravity, Windsurf, or VS Code.
# Your AI agent immediately inherits the 10 Golden Axioms and 3 Hard Gates!
# Initialize full Federated Agent Runtime with cryptographic boundaries
uaf init ./node-alpha --profile full --extension v3.0.1

# Verify custody provider & establish encrypted channel
uaf key-storage check ./node-alpha
uaf federation open ./node-alpha --peer node-beta.domain --channel-id SC-9042
